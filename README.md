# TITAN X V3 ULTRA — iPhone

Application PWA personnelle pour iPhone, utilisable avec **GitHub Pages**.

- Séances quotidiennes, exercices expliqués simplement, récupération intégrée
- Calendrier novembre 2026 – juillet 2027
- Rangs, XP, statistiques, records et chronomètre
- Sauvegarde et import JSON local, pas de compte ni serveur
- Fonctionne hors ligne après la première visite

## Publication sur GitHub Pages

Créer un dépôt public, déposer ces 7 fichiers à la racine, puis ouvrir **Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save**.
L’URL sera `https://VOTRE-PSEUDO.github.io/NOM-DU-DEPOT/`.

Dans Safari sur iPhone, ouvrir le site, bouton **Partager > Sur l’écran d’accueil**.

**Rappels à 18 h 30 :** créer un rappel quotidien dans l’application iOS Rappels ; GitHub Pages ne fournit pas de serveur push.

**Progression :** les données sont enregistrées uniquement sur l’appareil et sont associées au domaine. Avant de changer de domaine, exporter la sauvegarde JSON puis l’importer sur le nouveau site.
